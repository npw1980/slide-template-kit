# two-column-text-paired-boxes — Paired navy-header panels: prose side | numbered asks side

WHEN: A page whose whole job is "here is what we were told / here is what we were
asked to answer", with no chart. It comes from
`deloitte__deloitte_town_of_tillsonburg_it_strategic_review_council_upd` p4
("Project overview": two navy-banded panels side by side — Project Background as
prose, Objectives as bold-lead bullets) and p6/p8, where the review lists it as the
deck's device #2: "Boxed two-column mapping table with navy header band + gray
alternation". Use it for a mandate page, a scope/assumptions page, or a
drivers→findings mapping. Do not use it when one side is a number.

Panel geometry is fixed: A = x 76..624 (548 wide), gutter 32, B = 656..1204. The
panels start at y=150 and end at y=584 — the gutter between them is the page's only
horizontal break.

SLOTS:
- **claim title** — 11–15 words, hard max 2 lines. Good: a finding with its
  direction ("resolving the first two releases most of the deferred benefit").
  Bad: a topic label ("Project overview" is a *divider* title, not a page title).
- **eyebrow** — 2–5 words, the section/phase register. Never a sentence.
- **panel A header** — 1–4 words, the *kind* of content (Background & mandate).
  Lowercase sentence case renders better than ALL-CAPS here; the band already caps it.
- **panel A lead** — one sentence, ≤30 words, set in accent bold. It is the
  "so-what" of the panel: if you delete it the page must still read.
- **panel A prose** — 2 paragraphs of 4–6 lines. Justified. Real numbers with a
  source marker (`<sup>1</sup>`) — the deck's credibility device is footnoted
  specifics, not adjectives.
- **panel B header** — 1–5 words naming the question set, phrased as a question
  set ("What this phase had to answer"), not as "Objectives".
- **panel B items** — max 4 items × 2 wrapped lines. Each opens with a bold
  run-in lead naming the deliverable, then an em-dash clause that adds the
  qualifier. Item 5 overflows the band into a wall — the p4 failure mode.
- **source line** — every number on the page traces here; superscripts must match
  the body. Long is fine (it is 8.5px), blank is not.
- **running head** — page number then section, right-aligned.

FILL:
1. Replace `h1.title` text. Do not change `font-size`/`width` to make it fit —
   cut to 15 words or move detail into the lead line.
2. Set the two `.phead` strings. The band fill is `--panel-head`, text is knocked
   out white; do not add a second band colour.
3. Panel A: keep the `.lead-note` paragraph (accent bold), then two plain `<p>`.
   Add the third only if you delete one from the right panel.
4. Panel B: keep the `<ol class="asks">` at 4 `<li>`; the numerals are generated by
   CSS counters (`counter-increment:n`), so renumbering is free — do not hard-code numbers.
5. Superscripts: `<sup>1</sup>` in body must appear in `.source`; add `<sup>` pairs
   there for any new claim.
6. Zebra/alternating rows are available via `.zebra` (accent-soft tint) if the page
   is a mapping table with more than 4 rows; the sample leaves it unused.
7. Recolour: change `--panel-head` and `--accent` together. Everything else is gray.

CHART RECIPE: none — this is a text-only page. If a number belongs on the page it
goes inside panel A's prose or panel B's qualifier clause, with a footnote. If you
need a chart, this page has already lost the argument.

VERIFY:
- [ ] title ≤15 words and ≤2 lines at 27px in the 1000px column (render and look, don't guess)
- [ ] exactly two header bands, both the same navy
- [ ] one emphasis colour; the page must read as navy + grays (≤2 hues)
- [ ] white-on-navy header text clears 4.5:1 (#FFF on #051C2C = 15.9:1)
- [ ] source line present and its sup markers match the body
- [ ] page number + section bottom-right, on the same baseline as the source line
- [ ] no text within 24px of the stage edge (content box is 76..1204 × 46..694)

DON'T:
- Topic titles ("Project overview") — the claim sentence is the page.
- 9-item objective lists: that is the p4 wall the review flags. Cap at 4.
- Bold everything — bold is the lead-in only; body stays regular.
- Two accents (navy + green + gold like the source deck): the deck's own review
  counts 4 hues and calls the green/gold "accent + semantic", not a palette to port.
- Icons inside the panels. The device is type and bands, not clipart.
- Making panel B a copy of panel A's prose format — the contrast *is* the layout.
